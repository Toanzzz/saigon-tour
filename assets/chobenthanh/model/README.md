# Bến Thành Market

Stylized exterior model reconstructed from the five images in the parent folder. Proportions are artistic estimates from the supplied illustrations.

- `ben-thanh-market.blend`: editable geometry, materials, lettering, four review cameras, and studio lighting.
- `ben-thanh-market.glb`: portable building geometry and materials; excludes studio ground, lights, and cameras.
- `ben-thanh-market-preview.png`: three-quarter inspection render.

The building includes four arcaded facades, terracotta roof halls, a raised roof monitor, clock tower, Vietnamese entrance signs, striped canopies, and produce stalls. Interiors are not modeled.

Run `scripts/build_ben_thanh.py` in Blender's Python environment to rebuild. Run `scripts/export_ben_thanh.py` from the saved Blender file to export the building with lettering converted to meshes.
